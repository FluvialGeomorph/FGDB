# FluvialGeomorph ontology module

This directory is the design scaffold for FGDB's ontology and semantic
interoperability artifacts. It does not yet publish a normative ontology or
mint persistent terms.

The proposed architecture, standards profile, and governance questions are in
[`dev/architecture/semantic-interoperability.md`](../dev/architecture/semantic-interoperability.md),
with the initial mappings in
[`dev/schemas/ontology-crosswalk.md`](../dev/schemas/ontology-crosswalk.md) and
the proposed decision in
[`dev/decisions/adr-0007-semantic-interoperability-and-ontology-module.md`](../dev/decisions/adr-0007-semantic-interoperability-and-ontology-module.md).

Normative RDF sources should begin only after the team accepts the semantic
profile, answers the kernel competency questions, and establishes who governs
the persistent USACE namespace and publication endpoint.

# Workflows

## Maintained workflows

- `platform-compatibility-change.md` defines how platform, driver, library,
  service, schema-binding, and adapter changes are discovered, tested,
  accepted, migrated, and released without silently changing scientific data.
- `human-agent-collaboration.md` routes work among human experts, reasoning
  environments, and repository agents while keeping investigation
  proportionate.

Document repeatable, repository-relevant procedures here. A workflow should state its trigger, inputs, ordered actions, verification, and durable outputs.
